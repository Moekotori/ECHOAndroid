# 播放器与页面手势

## 页面切换、下拉与排序

这部分分别归属 `:core:design`、`:feature:player` 与 `:feature:library`，沿用现有翻页、边缘返回、下拉与拖拽触发区域，不增加全局指针拦截。

- **嵌套翻页**：手指位移与惯性使用一致的 RTL/反向布局换算；分页用不完的惯性继续交给父级。边界离页记住本次拖动的方向，纵向列表到头后的横向抖动不能重新判成离页；多指和页数变化取消该次离页。
- **详情返回**：仍只从起始侧 24 dp 边缘触发，支持 RTL。首次超过触摸阈值时决定方向；子列表/横向控件已消费的移动优先，纵滑不触发返回。取消、多指不提交，松手位置计入距离。
- **播放器收起**：超过阈值后的阻力可逆，结果不依赖 MOVE 事件数量；反向推回时只消费还原播放器所需的距离，剩余滚动交回列表。明显向上的甩动撤回收起；松手携带的最后位移参与结算。普通按钮对按下事件的消费不阻止随后未被子控件消费的纵向拖动，子列表、分页及滑杆仍优先。
- **队列与歌单排序**：队列保留长按触发，歌单保留显式手柄。跟踪原始手指，新增手指、父级接管或组件退出取消；只消费当前操作所属指针，真实松手才提交，松手最后一段移动计入目标。歌单提交前检查目标仍已加载。
- **拖拽自动滚动**：两处共用 `EchoDragAutoScroll`，靠边程度决定速度，按帧时间推进，速度上限为 750 dp/s。回到中部、松手或滚到边界时停止帧循环。底部内容留白用于避开浮动播放栏；队列查找落点直接遍历可见项，不在每次移动时创建候选列表。

相关验证用例是 `EchoPagerEdgeDragTest`、`EchoGesturePolicyTest`、`EchoDragAutoScrollTest`、`NowPlayingDismissMotionTest` 和 `NowPlayingGestureCompletionTest`；它们验证状态、方向与位移计算，不能代替真实指针分发验收。

本轮验证：

- 三个涉及模块编译通过，以上五组共 36 个用例通过（本次新增 8 个）。使用独立输出目录 `build/gesture-navigation/modules/`。
- `:core:design:lintDebug`：0 错误、7 个原有警告；没有本次手势实现的新条目。播放器与曲库的 lint 尝试被曲库编译的增量快照异常中断，未得到完整报告，没有添加抑制规则。
- 空资源缓存通过重新生成该模块资源解决；最终校验临时使用 `-Pkotlin.incremental=false -Pkotlin.compiler.execution.strategy=in-process`，用时 1 分 1 秒。项目构建配置未修改。
- 本轮没有打整包、安装到设备、做真实指针分发验证或性能采样。待手机复核的重点是嵌套翻页边界、点击后改为下拉、上推撤回、长按/手柄拖拽中的多指取消，以及自动滚动后松手落点。

## 播放进度

实现归属 `:feature:player`：`PlayerSeekInput.kt` 处理 Compose 指针事件，`PlayerSeekGesture.kt` 决定一次操作的方向、预览与提交。迷你播放器、标准/歌词进度条、唱片、像素、海报及使用 `ThemedSeekBar` 的主题共用这套行为。

- 点击在松手时跳转；超过系统触摸阈值的横拖开始预览，只有松手才发送一次 seek。松手事件携带的新位置也会计算。
- 首次超过阈值时，纵向或等幅斜向移动让给页面。方向确定后不因手指抖动改变；横拖可以移出轨道并在两端钳制。
- 第二根手指、父级接管、切歌、时长变化、禁用、布局方向变化、触觉配置变化或组件离开，都会取消当前操作并清理预览；不会把操作转交给另一根手指。
- 触觉沿用现有设置与有效性能档位，无常驻任务。进度绘制和触摸均支持 RTL；无障碍 `setProgress` 保留。电台仍不提供 seek。
- 保留各主题的轨道样式和现有触控区域；迷你播放器进度触区仍独立于封面、标题及播放按钮。

### 进度条验证边界

`PlayerSeekGestureTest` 用六个用例覆盖点击单次提交、横拖预览与松手位置、纵向/斜向让行、取消幂等、仅松手时发生的移动、边距/RTL/窄尺寸映射。

短验证命令：

```powershell
.\gradlew.bat :feature:player:testDebugUnitTest --tests '*PlayerSeekGestureTest' :feature:player:lintDebug --console=plain --max-workers=2
```

单测验证的是手势状态与坐标映射，编译和 lint 不证明真实指针分发或手机手感。真机复核重点是进度条上纵滑收起、横拖时页面保持、多指取消、拖动途中切歌，以及 RTL 下轨道与触点对齐；本轮未做真机触控或性能采样。

进度条改动使用 `build/gesture-refinement/` 下的独立播放器输出目录验证。六个单测通过；局部 lint 在分析已有 `RidgeBackdropField.kt` 时因缺少 `BackdropField.class` 触发 lint 内部异常，未得到完整报告，没有修改该文件或添加抑制规则。
