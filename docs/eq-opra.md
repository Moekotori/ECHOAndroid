# 声音调整与 OPRA

声音调整现在分为「均衡器」与「耳机校正」两个入口。

## AutoEQ 首次离线校正

耳机校正可切换 **AutoEQ · 离线** 与 **OPRA**。默认 AutoEQ，不会因第一次下载失败而无法使用校正；OPRA 保留原有在线下载、缓存和刷新行为。

`core:data/src/main/assets/autoeq/` 内置 8,850 个 AutoEq 数值配置，固定上游 revision `7ae0f56d53074872b028649617a22bbb4232feb7`，包含完整 MIT 许可证与来源说明。只导入公开校正数据，不导入 Salt Player 的实现代码。初始数值来自用户提供 APK 中注明许可的 AutoEq 数据；全部原始测量目录通过配置 ID 与上游 Git 文件树匹配恢复，全部 8,850 个配置重建后的原始参数文本均匹配上游 Git blob 哈希；SHA-256 和具体来源记录在 NOTICE 与 provenance.json 中。

同型号的不同测量来源/夹具可能生成不同配置，界面保留它们并显示来源、夹具、版本和原始配置链接，不将 AutoEQ 与 OPRA 或不同目标当作等价。按测量来源浏览，或直接搜索耳机型号；选择后复用现有曲线预览、PEQ 应用和收藏。以 `autoeq:` 前缀隔离 ID，原有收藏字段及存储格式兼容，不迁移数据库。

读取在后台执行，按需加载一份有界不可变目录；校验版本、条目数、重复 ID、滤波器种类和参数范围。任意损坏/不支持滤波器导致目录加载失败，不静默裁剪曲线。PEQ 增益上限由 +18 dB 扩为 +20 dB，保留目录中 78 个含较高滤波增益配置的原值；原有前级增益、削波提示和 bit-perfect 旁路规则仍适用。

当前 AutoEQ 目录**随应用版本更新**；“查看更新”打开上游项目，并非后台下载新目录。上游没有供本实现直接读取的同格式整库发布地址，不能假装点击即在线更新。维护者可从干净、固定 revision 的上游 checkout 重新生成：

```text
python scripts/import-autoeq.py --checkout /path/to/AutoEq
gradlew.bat :core:data:testDebugUnitTest checkLocalization
```

生成器保留原始文件路径产生的稳定 ID、测量夹具、原始前级与滤波参数，确定性压缩后同步更新许可证和 NOTICE。升级目录时检查新增数值是否超出播放器支持范围，不截断到支持范围内。

## 本次修正

- 搁架滤波器按 OPRA 的 Q 值计算，不再把 Q 当成 RBJ 的 S 参数。
- 高通/低通按 6–36 dB/oct 构造 Butterworth 级联；支持 band-pass。
- 不支持或损坏的 OPRA 滤波器会导致整条预设被拒绝，不会只应用其中一部分。
- EQ 开关改变处理链是否启用时，重新配置播放 sink；调节已启用的曲线时更新现有滤波器。
- 预增益同时适用于手动 EQ 和 OPRA，并保留到设置。OPRA 激活时不会被残留滑块事件覆盖成五段 EQ。
- 图表来自与音频处理相同的滤波器公式，是 48 kHz 参考响应，包含预增益；不是实测耳机频响。
- 建议预增益是采样曲线估算，不保证所有瞬态、其他增益处理或已有失真的音源都不会削波。
- 页面区分 EQ 关闭、等待音频、PCM 实际进入处理器、bit-perfect 旁路。保存预设不等于已经听到校正。

## 数据与交互

OPRA 下载支持取消和请求替换；数据库在数据层串行加载，完整验证后原子替换缓存。
下载限制为 32 MiB，正常缓存有效期 24 小时，网络失败可使用原缓存。过期缓存回退后短暂抑制重复联网。
数据库首次下载后可离线搜索；修改搜索文本会取消旧请求，旧结果不会覆盖新查询。
应用动作位于选中曲线预览旁，保留原作者、来源链接和 OPRA 署名。

为完成界面回归，还修复了启动动画的时长边界：小于 110ms 的动画不再触发空区间异常。

## 已做验证

2026-09-08 的在线发布数据：714 品牌、6,230 型号、12,594 曲线；应用解析器能检索 HD 650 的 13 条预设。
针对性 JVM 测试覆盖搁架 Q 参考值、不同低通斜率、实际 PCM 增益、预增益恢复、OPRA 防覆盖、参数序列化与损坏数据拒绝。
真实数据库另做了一次解析与型号检索验证。Android Debug APK 构建通过。
模拟器点击流程已验证：HD 650 搜索、应用 AutoEQ / oratory1990 的 10 个滤波器与 -6.1 dB 预增益，强制停止并重启后仍恢复为完整参数校正。测试没有开启有声播放。

仍需结合具体耳机和真实输出设备试听。曲线的数学正确性不证明该预设一定适合个人佩戴、耳垫、耳机批次与听感偏好。
