# 无缝播放与淡入淡出

## 行为

- 默认按 Media3 连续队列播放，下一首预加载的目标时长为 5 秒，保持兼容的输出会话。
- 自动切歌和单曲循环不再根据可能缺失的曲库采样率信息插入额外 USB 静音；实际格式变化交给 sink 排空和配置。
- Media3 按文件提供的 encoder delay / padding 信息处理编码补齐，乐曲本身的静音保留。
- 设置 → 播放设置可启用「曲首淡入 / 曲尾淡出」，范围 0.5–5 秒，默认关闭、默认时长 1.5 秒。
- 设置 → 播放设置可启用「智能过渡」（Beta，默认关闭）。仅本地、1.0 倍速、非 USB 独占。根据首尾能量选择重叠；有可信拍点时选择临近入点，人声冲突时缩短为 0.5–1 秒的平滑淡化，高能量时低频错峰。普通重叠 1.5–4 秒，不再仅凭人声启发式估计做 60 ms 硬切。做不到则走无缝播放或淡化。轻量档 / 省电、同专辑连续曲号、远程流、直播、单曲循环、已有 CUE/源区间裁剪的曲目不叠。采样率不一致会把混音窗口重采样到当前输出。不变速。
- 短曲目将每侧淡化时长限制在曲长的一半。跳转到曲目中间不会重新从零淡入；暂停时停止调度，恢复后沿当前曲目位置继续。
- 淡化实现独立曲首/曲尾包络，不重叠播放两首歌。直播不淡化；没有可靠时长的非直播曲目只能淡入，不能预测淡出点。
- 智能过渡在 mixer AudioProcessor 里叠下一首已预解码的短窗口（≤1.5 MB）。开启时 mixer 透传激活（一次拷贝，offload 不可用）；关闭后完全旁路。分析只解 intro/outro 各最多 16 秒、11025 Hz 单声道，缓存 32 条 / 2 MB 文件，不进 Room。缓存键包含源文件大小/修改时间（来源提供时），文件名使用版本化 SHA-256，磁盘缓存 24 小时过期。混音原始解码缓冲另限 8 MiB，超预算或窗口不足直接回退。
- 严格 bit-perfect 下保持单位增益，保存淡化偏好但不应用；退出严格模式后恢复。

## 实现

`EchoTrackTransitionController` 由播放服务创建/释放，使用 ExoPlayer 的实际位置和时长。
`EchoSmartTransitionController` 在剩余约 25 秒时分析（高性能档可提前分析下一首 intro），重叠开始前约 8 秒预解码；由 `EchoTransitionClockAudioSink` 提供扣除流偏移后的真实媒体时间戳，DSP 在 flush 后锚定，mixer 按 PCM 帧位置进入重叠，不估算固定的缓冲提前量。armed 时抑制单轨淡出。自动切到预定队列项后，按实际混入帧数 seek 到原曲对应位置；手动切歌、重复 ID 的其他队列位置或未发生混音都不跳过开头。不再改写 MediaItem 的 clipping，原曲时长和歌词时间线保持一致。
淡化窗口中每 20ms 更新一次平滑余弦音量包络；窗口外等待下一边界，不常驻高频轮询。
暂停、缓冲、跳转、变速、队列变化和切曲事件会取消并重新安排任务；省电档和睡眠定时策略变化通过 Flow 触发失效。解码与磁盘缓存访问在后台，解码循环检查取消，超时失败不使用半截分析结果。停播和旁路时不轮询。不是逐样本包络。
包络与 ReplayGain、睡眠渐弱相乘，统一通过原音量处理路径输出，不建立第二个播放器。
偏好由 DataStore 保存，Application 同步运行时设置，媒体会话恢复前也会读取设置。

## 验证与边界

- 5 项纯逻辑检查：关闭、起止包络、短曲目、未知时长和调度/变速。
- 智能过渡：资格旁路、能量重叠钳制、等功率曲线、mixer 透传/交叉、分析缓存淘汰。仪器测试未加。
- 2 项 Android 检查：两段 WAV 的 8,000 帧逐帧一致且只创建一个 AudioTrack；淡化按实际播放时钟运行，严格模式旁路。
- Android 检查静音运行，没有进行实际耳机试听或录音测量；仪器测试未加入默认 CI。
- 不同输出格式/采样率可能需要重配 DAC，网络欠载也可能中断，不能保证这些条件下无缝。
- USB 真机、不同编码器的 MP3/AAC 补齐信息和远程鉴权来源仍需结合实际媒体验证。

### 智能过渡本轮验收边界

- 定向 JVM 测试覆盖 PCM 双端裁切、混音结束、seek 时钟、连续交接状态、手动/错项交接保护、缓存键冲突及淡化策略。
- 自动交接使用 Media3 seek 续接，可能受设备解码器和输出重新缓冲影响；单测不等于已证明样本级无缝，仍需真机耳机试听或输出录音检查边界。
- 不新增默认仪器测试或长时间性能采样。
