# 专辑和歌单 NFC 标签

仅支持 Android 本机曲库。专辑或本地歌单详情右上角菜单提供「写入 NFC 标签」；不支持 NFC 的手机不显示入口。支持已格式化的可写 NDEF 标签，以及 Android 能格式化为 NDEF 的空白标签。

## 写入与播放

1. 打开专辑或本地歌单，选择「写入 NFC 标签」。
2. 将标签靠近手机背面并保持不动。NFC 未开启或系统禁止标签启动 ECHO 时，可前往设置修改后返回继续。
3. 标签已有内容时先确认替换，再移开并重新靠近。只读、容量不足或连接中断均有提示，不显示成功。首次格式化的标签需要移开后再次感应，以回读验证。
4. 写入、回读验证和本机绑定保存均完成后，才显示成功。之后手机解锁并开启 NFC，碰一下标签即可打开对应专辑／歌单并调用现有播放入口。相同标签 2.5 秒内的重复启动会合并，不重复替换播放队列。

## 失效重绑

内容删除、变为空歌单，或换机／清除应用数据后，碰标签会显示重新绑定入口。搜索并选择本机专辑或歌单即可保存新绑定，不必再次写卡，也支持只读的既有 ECHO 标签。每类最多展示 40 项，搜索在数据层执行，替换搜索会取消旧请求。

搜索或选定内容失败后，重试保留当前关键词并返回选择列表，不重新加载旧绑定。

标签只包含 `application/vnd.app.echo.android.music` MIME 记录及 `echo-music:1:<UUID v4>`，没有数据库 ID、文件路径、音频地址或凭据。绑定在本机 DataStore 单独保存，不进入可移植设置备份；同一标签可在不同手机绑定不同内容。最多保存 256 个绑定，达到上限会报保存失败，不静默淘汰其他卡片。

专用 NFC Activity alias 使用 `DISPATCH_NFC_MESSAGE` 保护，主 Activity 保持原有桌面与媒体入口。NDEF 读写、回读及曲库查询在 IO 调度器执行；读卡模式仅在标签操作期间、Activity 前台恢复时启用，暂停／关闭弹窗时释放。没有后台读卡服务、轮询或新播放器。

## 验证边界

定向 JVM 用例覆盖版本化负载拒绝、绑定重绑与损坏／超限数据边界，以及慢速曲库查询期间保留启动请求、查询取消后的请求保留和新请求对旧查询结果的替换。真实标签的读写距离、首次格式化、覆盖确认、只读标签、应用冷启动和不同厂商系统仍需 NFC 真机验证；编译和 JVM 用例不能替代这些验收。
