# Android 歌单与播放整理功能

本批功能只涉及 Android。

| 功能 | 入口与行为 |
| --- | --- |
| 独立文件歌单 | 歌单列表的“文件歌单”，选择文件或文件夹后创建；文件夹包含子目录。条目存入独立表，音乐库扫描、全部歌曲随机和智能歌单不会混入这些条目。 |
| 播放器方向锁定 | 设置 → 播放 → 歌词与播放器，开启后手机展开播放器保持当前方向；收起、离开前台或关闭选项时恢复原方向设置。平板不强制锁定。 |
| 静音自动暂停 | 设置 → 播放 → 聆听，默认关闭。应用静音或系统媒体音量静音时暂停，仅恢复本功能拥有的暂停；手动播放、暂停、切歌、输出改变或过期睡眠定时器会阻止错误续播。USB 独占输出不受系统媒体音量控制，严格位完美模式忽略应用静音。 |
| 歌单导入纠错 | 导入预览 → 核对匹配，逐项选候选、搜索曲库或跳过；保留原条目次序，重复歌曲沿用既有去重规则。候选显示路径以区分重名歌曲。 |
| 扫描排除与明细 | 添加音乐 → 扫描规则，设置文件名关键词；扫描结果 → 扫描明细查看分类计数、样例并返回规则。 |
| 仅当前句译文 | 播放器歌词设置 → 内容，开启仅当前句显示译文；手动翻看时显示译文。隐藏文本保留高度，避免行间跳动。 |
| 本地歌曲星级 | 歌曲菜单或信息页设置 1–5 星、不评分，或重新读取文件星级；曲库筛选、排序和智能歌单支持最低星级。手动评分优先于文件标签，重新扫描保留手动评分；此功能不写回音频标签。 |
| 艺术家头像 | 艺术家页选择图片、匹配图片文件夹或恢复自动。优先级为手动图片 → 本地人物图片 → 服务端头像 → 原封面回退。所选图片复制至应用目录，扫描和网络刷新不会覆盖手动图片。 |
| 队列搜索 | 播放队列搜索歌名、歌手或专辑，显示各次出现的位置，点击播放原队列项；不会重新插入歌曲。 |
| 可读歌单导出 | 歌单菜单 → 导出歌单，选择 M3U、TXT 或 CSV。TXT/CSV 含序号、歌名、歌手、专辑、时长；CSV 为 UTF-8 BOM，正确转义引号和换行。 |

文件歌单保存文件引用，不复制音频；原文件移动、删除或权限失效后需要重新选择。每张最多 2,000 项、最多 100 张文件歌单；遍历最多 2,000 个目录、20,000 个目录条目。现有音乐库备份不包含独立文件歌单及其音频。

在文件歌单的编辑模式中，可继续从文件或文件夹追加音频，也可从音乐库添加。按 URI 去重，已有条目保持不变；容量在读取新文件之前检查，提交时再次检查。文件歌单分页在内容更新时保留刷新位置，翻页共享当前有界快照。

大量文件建议选文件夹：创建前会检查持久授权预算，避免逐文件申请挤掉已有授权。文件歌单条目不进入音乐库收藏；播放器隐藏对应收藏入口。文件歌单复制、导出及系统播放入口遵守保存的排序。

本地人物图片使用 `artist_艺术家名.jpg/jpeg/png/webp` 精确匹配。手动图片独立保存；自动发现检查艺术家曲目所在的最多三个目录，也可主动选择人物图片目录。

扫描明细保留分类计数和最多 40 个样例。跳过目录时只统计已检查的目录，不为未遍历的内部歌曲推测数量。读取失败的已有歌曲保留原信息以便重试。关键词为文件名的不区分大小写的字面匹配，最多 50 个，每个 64 字符。

数据库版本从 29 升至 30，新增评分字段、智能歌单最低星级和独立文件歌单表；沿用兼容迁移，不清空曲库。星级在下一次扫描时补读旧条目，随后仍走增量路径。
