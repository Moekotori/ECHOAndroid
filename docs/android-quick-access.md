# Android 快捷入口与设备音效

本轮只修改 Android，不改变 Echo Link 或 ECHOSteam 契约。

## 桌面快捷方式

专辑、歌单详情页的「添加到桌面」可选择打开详情或直接播放。系统桌面会展示自己的添加确认；不支持的桌面会收到提示。标识只保存曲库 ID，不保存音频地址或凭据。内容失效时提示并禁用对应入口。

从首页、曲库或桌面入口播放专辑/歌单后，长按应用图标可看到最近使用的动态入口。动态数量服从桌面限制，最多四个，并为现有静态入口预留名额；名称在再次使用时更新。

## 小组件配置

添加四种播放组件时进入配置页；支持重新配置的桌面也能修改已添加组件。每个实例独立保存封面、歌词、上一首/下一首按钮和背景不透明度，可搜索绑定歌单。保存前显示内容预览。封面样式保留图片及文字遮罩的不透明度。

绑定歌单后，大组件增加独立播放入口；窄条组件点击背景启动所选歌单，播放/暂停按钮仍控制当前队列。控制按钮数量受可用尺寸限制。取消首次配置不会接受添加；保存失败会显示错误并允许重试。删除组件清理实例配置；保存时也会清理过期配置，最多保留 64 个实例。

组件沿用实际播放状态与有界封面缓存，不新增进度轮询或播放器。关闭封面时不加载封面。

## 设备音效配置

进入「信号 → 声音」，在设备音效区域保存或更新当前输出的配置。保存均衡器（含参数均衡器）、MSEB、ReplayGain、完整声道平衡及切歌设置。最多 16 个设备配置，超出时淘汰最早保存的配置。

设备切换由应用的播放运行时监听，锁屏和仅服务运行时也使用同一接线。一次设置事务完成切换；离开绑定设备或解除绑定时恢复进入配置前的通用设置。修改音效后需点击更新，才会保留到该设备的配置。既有 EQ 单独绑定保持兼容，完整设备配置优先。

USB 位完美模式继续绕过音效处理，配置不会改变 USB 独占选择、位完美选择、系统音量或账号设置。当前设备识别沿用输出类型和系统设备名称，同名设备可能共用配置。

## Android Auto 语音选歌

Media3 会话处理歌曲、专辑、歌手、歌单和流派查询，并优先采用系统提供的查询类型。歌曲查询结合歌手/专辑信息筛选重名内容，并从选中的歌曲位置起播；专辑和歌单按各自已有顺序建立队列。空查询选择最近听过的音乐，没有历史时使用最近加入的曲目；无结果返回错误，不选取无关内容。

同时支持平台 `MEDIA_PLAY_FROM_SEARCH` Activity 入口。查询和数据库读取在后台完成，替换请求取消旧工作；沿用外部媒体会话的 200 首队列上限。

## 系统文件选择器中的 ECHO 曲库

其他应用通过系统文件选择器添加音频时，可在「ECHO 曲库」进入专辑、普通本地歌单或全部歌曲，也可搜索歌曲、歌手、专辑及文件名。多选由调用应用的系统选择器配置决定。歌单沿用歌曲顺序，只列出本地音频；远程来源、隐藏歌曲和智能歌单不在本轮范围内。

目录只用于浏览，不开放整目录授权。接收应用通过系统授权读取选中的原文件，可请求持久读取权限；没有分享缓存的 24 小时限制。读取时重新核对曲库可见性与来源，文件删除、隐藏或底层访问权限失效后会拒绝读取。只读 Provider 不支持创建、写入、删除或改名，不转码，也不复制整份音频。

CUE 曲目按同一原文件合并为一个文档，始终读取整份原音频。列表通过数据库游标返回，不在内存中复制整份曲库；查询支持系统分页参数，普通查询不会静默截断。Room 的曲库、隐藏状态及歌单变更会通知已经打开的选择器刷新。

边界处理：零行分页返回空结果，根目录同样遵守分页；新式排序参数与旧式 SQL 排序均只接受白名单字段，反馈实际处理的参数。搜索可单独按 MIME 类型筛选，也支持大小和修改时间条件；MIME 值会去除参数并归一大小写。旧曲库缺少文件名时，根据已知音频类型补充显示用扩展名，原文件不变。首屏 SQL 读取失败时关闭游标，保留请求的列结构及刷新订阅，并显示恢复提示；取消异常继续传递。失效文件或访问权限变化统一返回文件不可用提示。

## 合并重复版本

入口为曲库的「自定义分类 → 合并重复版本 → 管理」。点击「分析并合并」后，手机本地歌曲列表及从该列表新建的播放队列只保留每组代表版本；开关关闭后恢复全部记录，已经开始播放的队列保持原样。专辑、文件夹和普通歌单保留实际内容与顺序，原音频、收藏及歌单引用不删除、不合并改写。歌曲菜单中的「歌曲版本」可查看其他版本、读取到的技术参数及本地路径，并指定首选版本。

匹配使用曲库中的同一专辑身份、完整标题、歌手、时长和片段边界；标签相同但属于不同专辑身份的记录不会自动合并。保留 Live、Remix、重制等标记，避免变速文件和相互不一致的曲目/碟号混入。同组任意两首的时长差不超过两秒，避免相近时长逐条串联成大组。分析以 32 个候选桶分页，单桶超过 256 条则保留原样并提示，文件元数据顺序读取，不解码整份 PCM、不计算整文件哈希。

推荐依据已知编码格式、位深、采样率及码率；未知参数不假设为高规格，容器名不代替已识别的实际编码。该推荐是技术参数排序，不是母带来源、无损真伪或听感鉴定。手动首选优先；开始播放时会核对文件是否可用，并在代表文件缺失时回退、展开失效索引。启用后，其他本地播放入口也会使用相同的版本解析策略。

Room 28 增加派生的版本成员与控制表，不改原曲目 ID。分析用新一代索引暂存，完成后事务发布；取消或失败保留已有结果，暂存写入不触发歌曲列表反复刷新。曲库扫描发现元数据变化、代表记录被移除/隐藏或播放解析发现文件不可用后，失效索引不会继续隐藏其他版本。改动曲库后可重新分析。分析统计表示上次分析结果，文件总量统计仍保留真实文件数量。

深化边界：文件名中的现场、混音、重制年份和整数/小数变速标记也参与判断；中、英、日未知元数据占位不作为同曲依据。文件名、曲目号、碟号、年份变化会使旧快照失效。首选按本地专辑身份隔离，版本详情重新核对当前可见记录，回退排除不匹配专辑和版本标记。发布前剔除已变化/隐藏/删除的暂存成员，重新选择有效代表并统计；不足两条的分组不折叠。扫描若中途启动，会停止本轮分析并保留已发布结果。

管理和版本选择使用底部面板，统计、开关和操作优先显示，规则说明可展开。版本按格式、音频参数和路径逐行对照，首选与推荐分别标注；保存失败可重新加载版本信息。

## 原音乐文件分享

曲库单曲菜单、播放器菜单与多选菜单提供「分享原文件」，一次最多选择 200 首本地歌曲，可选附带歌词和封面。远程来源会提示跳过，不下载音源；本地原文件无法读取时停止准备并保留选择，可取消或重试。

音频通过只读 URI 直接提供原文件，不转码、不复制整批音频。相同原文件只分享一次；不同格式的同名歌曲会分配不同文件名，其歌词和封面沿用对应文件名。CUE 与片段分享整份原音频，歌词时间会加上片段起点与用户偏移；共用原文件、封面的 CUE 曲目不重复附带封面。

歌词提供毫秒精度的 LRC 或纯文本；逐字时序、声部、明确结束时间等额外信息另附 `.echo-lyrics.json`。只使用已有选择、本地与匹配的已缓存歌词，不联网搜索。缺失附件在继续分享前列出数量。

分享链接有效期 24 小时，附件缓存最多 64 MiB、64 个会话，过期缓存在下一次分享时清理。Provider 仅接受被授权的具体文件 URI，拒绝写入；清单可跨进程重建，最多保留两个解码后的清单。应用进入后台时保留准备结果，回到前台后由用户继续分享。
