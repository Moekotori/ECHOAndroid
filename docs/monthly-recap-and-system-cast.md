# 听歌月报与系统 Cast

## 听歌月报

从首页或播放历史进入听歌统计，再点「听歌月报」。可以切换自然月；当月标记为进行中。页面显示有效收听次数、累计时长、活跃天数、24 小时收听分布、重听专辑和新发现歌手。

- 日期和时段使用收听记录写入时的本地日期/小时，旅行或改时区不会移动旧记录。一次收听的累计时长归入开始收听的日期。
- 新发现歌手：在当前保留的历史中，首次出现的月份是所选月。清除或删除历史可能改变这一判断，不代表真实人生中的首次收听。
- 重听：不计每首曲目在当前保留历史中的首次记录。专辑在曲库中时用既有 albumKey 分组；曲目已删除时用记录中的专辑名和歌手分组，避免直接合并不同歌手的同名专辑。
- 聚合在数据库事务和 I/O 调度器内完成，返回前五名及固定 24 个小时桶。新发现和重听的首次记录判断会读取历史索引/聚合，不把整份历史载入界面。

分享页提供浅色与深色卡片，同一张 1080×1350 位图用于预览、分享和导出。最多加载三张 256 像素封面，按平方裁剪保持比例。分享通过本 feature 的独立 FileProvider，仅授予当前分享图片的读取权限；缓存最多六张 PNG。文件导出在打开系统文件选择器前固定图片，避免返回时内容或样式发生变化。

## 系统 Cast

使用官方 Cast Sender 22.3.1 和 MediaRouter 1.8.1，接入 MediaTransferReceiver、SDK 会话和回切事件。Android 13+ 且 Google Play 服务及 Cast 模块可用时，系统媒体面板和播放器投放抽屉可打开系统输出选择器。原 PC、DLNA 和手动 Chromecast 入口继续可用。

- 本地到远端：从 MediaController 读取真实队列和位置，按实际随机遍历顺序准备播放窗口。复用现有原文件 HTTP 服务；使用到接收端的有界 TCP 探测选择 LAN 地址。沿用最多 50 首、接收端 IP 限制与格式检查，不转码，不向接收端发送账号凭据。
- SDK 确认加载成功后才暂停手机；初始化、权限、来源、格式或加载失败时保留手机队列。发布窗口以后的歌曲不会自动扩展为无界队列。
- 远端到手机：只接受本次发布的媒体 URL，映射回原队列项身份和真实位置，保留播放/暂停状态、手机完整队列及原随机设置。队列重排后按项身份查找；已替换的队列不被旧回切覆盖。
- 断连和接收端播放错误：清理发布服务，保留手机队列，并在可确认曲目身份时恢复到暂停位置。主动停止投放不会自动播放手机。
- SDK 状态和每秒进度回调分别更新已有远端状态/位置，不轮询接收端网络。连接、发布、结果等待和线程数量有界；结束时释放控制器及进度订阅。进程死亡后不凭陌生的接收端内容自动替换本地队列。
- Google Play 服务不可用的设备保留原投放方式。CUE 片段、无法发布的来源和既有 Cast 格式策略不支持的文件会提示失败。蓝牙/USB 均衡器仍属于手机输出，不能解释为接收端音效。

## 验证

相关 Gradle 编译、Debug 打包、模块和语言检查通过。定向单测覆盖月界/闰月、发布内容识别、队列替换和重排、位置边界；`python core/data/src/test/python/monthly_recap_sql_test.py` 直接运行 DAO 查询的六项 SQLite 检查。

隔离 Android 16 模拟器使用八条合成收听记录：自然月切换、总量/新歌手/重听计数与 SQLite 结果一致；分享页和系统图片分享选择器可用，实际生成 PNG 为 1080×1350，预览与导出共用位图。原应用未被覆盖。真实 Cast 接收设备、本地到远端/回切、锁屏连续性、网络断连及多设备扩展仍需硬件验收，编译和策略单测不构成这些场景的通过证据。
