# 歌词来源与显示位置

设置 → 播放 → 歌词：

- **歌词界面**：打开播放页的歌词界面，页内设置可调整样式、字体、对齐和翻译显示。
- **歌词获取顺序**：上移、下移 SPL / LRC 与其他同名文件 / 内嵌歌词，完成后立即重新加载当前歌曲。手动导入、编辑或选定的歌词始终优先；失败来源不会阻止后续来源。在线匹配保持独立开关。
- **桌面悬浮歌词**：授权后在应用退到后台且正在播放时显示当前行与下一行；未锁定时可拖动，锁定后触摸穿透。字号及位置持久保存。
- **通知栏歌词**：控制媒体通知的当前行显示，关闭后恢复歌手信息。部分 Android 系统使用媒体会话元数据渲染通知，可能不显示通知提供者的自定义文本。
- **悬浮窗状态栏歌词**：独立迷你单行窗口，可调字号、宽度、左右及上下位置。暂停、熄屏、锁屏、无当前歌词时隐藏；点击穿透。Android 将普通悬浮窗放在系统状态栏下方，因此不能保证覆盖状态栏空白处。
- **系统级状态栏歌词**：Flyme 实验性 ticker 兼容，默认关闭。只在魅族设备允许启用；是否显示仍取决于 Flyme 版本和系统设置。如媒体通知异常可立即关闭。
- **状态栏歌词不显示翻译**：同时控制两种状态栏模式；关闭时合并主歌词与已解析的翻译，不影响播放页或通知栏文本。

所有歌词窗口共用播放服务的歌词快照，按行边界调度，不增加 UI 帧级或后台固定频率轮询。状态栏窗口随播放服务销毁释放；权限不足时提供授权入口。

SPL 支持行结束标记、重复开始时间、方括号及尖括号逐字标记、首字延迟、相同时间戳及紧邻的多行翻译、offset。自动识别同名 `.spl`，也可手动导入。Android 的媒体文件访问权限不保证能读到所有旁置文件，无法访问时可手动导入。

实现归属：共享偏好在 `core:model`，持久化在 `core:data`，SPL 解析在 `core:lyrics`，通知和状态栏窗口在 `core:playback`，设置 UI 在 `feature:settings`，现有桌面窗口和权限/页面接线在 `app`。未增加模块或更改 PC / Echo Link 协议。

依据：[SPL 标准](https://moriafly.com/standards/spl.html)、[Android 悬浮窗口层级](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_APPLICATION_OVERLAY)、[Media3 项目的 Flyme ticker 接口说明](https://github.com/androidx/media/issues/1833)。
