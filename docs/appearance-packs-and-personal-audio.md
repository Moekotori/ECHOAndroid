# 外观包与个人听音

## 场景与外观包

播放器 → 外观 → 场景与外观包。导出时输入名称并选择保存位置；导入后先查看排版、
背景与配色示意，再点击应用。播放器场景、动画与导入字体由实际播放器呈现。
「恢复应用前的外观」保留一层撤销，重启后仍可使用。

外观包包含播放器内置样式、歌词排版、逐字高亮、翻译/音译显示、配色及可选静态背景、
歌词字体；视频背景不导出。此格式是 Android 的声明式外观包，不直接执行 Steam 工坊
主题或任意网页、脚本，也不会变更账号、曲库、播放、设备、语言或性能档位。

启用动态配色的包会跟随目标设备壁纸，预览会单独提示。

格式为 `.echoappearance.zip`，根目录只接受 `appearance.json`、可选 `background`、可选
`font` 三个文件。JSON 的 `format` 为 `echo-android-appearance`，`version` 为 `1`，
其余字段对应 `:core:model` 的 `EchoAppearancePack`。枚举和值域严格验证；未知版本、
重复条目、其他条目和路径穿越均拒绝。导出结果可重新导入。

压缩包与解压总量各不超过 12 MiB；JSON 32 KiB、背景 8 MiB、字体 4 MiB；背景最长边
8192 像素且总像素不超过 16777216，字体限 TTF/OTF/TTC 并验证可加载。资源复制到应用
私有目录，原文件不会被改写。应用和撤销使用同一 DataStore 事务；成功后清理不再被设置
或撤销引用的旧资源。I/O、解析、图片尺寸与字体验证在 IO 调度器上进行。

## HRTF 耳机声场

信号 → DSP → HRTF 耳机声场。默认关闭，只处理普通立体声 PCM，USB 位完美使用独立
直通链路并旁路。使用耳机试听窄/标准/宽三种虚拟音箱角度（±20°、±30°、±45°），
可调混合比例；与交叉馈送互斥。它使用通用实测响应，不保证每个人都会获得头外定位。
本版没有头部追踪、SOFA 导入或个人耳形测量。

数据来自 OpenAL Soft 固定修订的 SADIE II 衍生 HRTF，按 Apache-2.0 分发；保留完整许可
与来源并在设置的开源协议页列出。这里只包含数据，不包含 OpenAL 播放引擎。
`core/playback/scripts/compile-headphone-responses.py` 可重现生成固定系数，运行时不联网。

每方案四条 48 kHz、128 taps 的响应；流格式配置时重采样，支持 8–96 kHz，每响应最多
256 taps。更高采样率明确旁路 HRTF，避免直接卷积随采样率平方增长；动态等响仍可使用。
音频线程使用有界历史缓冲，一次 JNI 调用处理最多 1024 帧，逐帧不分配对象。
启停平滑，切换方案先淡出到原音再淡入；seek/flush 清空历史。响应包含共同的约 0.33 ms
保护延迟及实测耳间延迟；不增加整块 PCM 缓冲。曲目结束仍沿已有帧数结束，不额外延长
最后不足约 3 ms 的 FIR 尾音。开启后会改变数字信号，保留最终峰值保护。

## 动态等响补偿

同一 DSP 页开启动态等响补偿。参考值使用应用 PCM 音量的 `levelDb`，不使用 Android
媒体音量、蓝牙音量或 DAC 硬件百分比，也不把 ReplayGain 当作听音音量。
参考处补偿为零，低于参考 20 dB 达到最大；低频/高频最大补偿分别可调至 12/6 dB。
100 Hz 低频与约 4500 Hz 高频的一阶响应平滑变化，位于最终增益和峰值保护之前。
此功能改善小音量的相对频率平衡，不构成耳边声压或 ISO 等响曲线校准。

两项设置均持久保存、进入迁移备份与设备音效配置。默认关闭，复位关闭，位完美旁路；
不改变 Echo Link 协议。单测与编译无法证明真机听感、所有 DAC 兼容性或实际耗电。
