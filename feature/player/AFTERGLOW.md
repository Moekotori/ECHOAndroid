# Android Afterglow

歌词设置保留 `afterglow_mist` / `afterglow_night` 两个稳定 ID。舞台的场景按钮可以手动选择，也可按每两句歌词轮换。配色、场景选择和随机编排属于当前舞台会话；样式继续参与原有设置和备份保存。

Afterglow 使用独立的全屏播放布局，背景直接铺到屏幕边缘，歌词、罗马音和译文在场景里排版。选择样式后关闭设置面板并进入演出；曲目信息、进度、播放和场景按钮默认隐藏，轻点显示/隐藏，闲置约 4.5 秒自动收起。拖动进度和打开场景菜单期间暂停自动隐藏。控制层只覆盖场景，不压缩或移动歌词舞台；离开时恢复系统栏及普通封面布局。

## PC 场景移植

| 雾景 | 夜航 |
| --- | --- |
| 雾山棱线 `echoMistRidge` | 星海航行 `echoVoyage` |
| 紫藤花架 `echoWisteria` | 极光 `echoAurora` |
| 湖畔晨雾 `echoLakeMist` | 星图 `echoStarChart` |

主构图、几何比例和主配色来自 echosteam 的 [雾景绘制器](https://github.com/moekotori/echosteam/blob/4857cc1d78901a6786073d4e2eb0c321169d5f01/src/renderer/components/lyrics/jizura/jizuraBackdropsEchoMist.js)、[夜航绘制器](https://github.com/moekotori/echosteam/blob/4857cc1d78901a6786073d4e2eb0c321169d5f01/src/renderer/components/lyrics/jizura/jizuraBackdropsEchoNight.js) 与 [signature looks](https://github.com/moekotori/echosteam/blob/main/src/renderer/components/lyrics/jizura/jizuraSignatureLooks.ts)。用 Kotlin / Android Canvas 原生绘制；静态细节预绘制，移动的船只、行星、花瓣和星光采用有上限的动态层。纸色场景的逐字墨迹调深以保持山景上的可读性。

移植范围不包含 Workshop 包、Afterglow Cover、PC 的完整字形引擎、全部后处理及每一种动态细节。音频链路、Echo Link 协议和 PC 实现不变。

## 歌词演出编排

按句长与文字类型，确定性选择大字冲击、错落分行、一字聚焦、双栏竖排、侧边留白和低位字幕六种编排。方向参考 PC 的 `huge` / `mixed` / `kanjiFocus` / `vcols` / `tyMargin` / `subtitleBar`，采用独立的原生实现。五字以内优先大字；竖排限纯 CJK 短句（最多十二字），复杂文字保留完整段落字形。大字使用显示粗体，一字聚焦使用低透明度轮廓字；辅助文本仍按原文排版。

字形位置、行偏移、行裁剪、字号和显示高度在后台一次准备。错落段落只重画裁剪内的一行，竖排最多十二个字形。入场采用分字上浮与短推镜，持有阶段只做轻微漂移，退场使用小幅后撤与淡出；所有动作从歌曲时间推导，Seek 后还原相同编排。轻量档采用简洁静态字幕。保持全屏和控件默认隐藏。

这轮大字、竖排、错落和聚焦已在真实播放页以短句、长日文和译文做截图检查，另加一句长/语言限制回归用例。下面的性能对比采自上一轮合并绘制版本，不能直接当作本轮六种演出的新性能测量结果。

## 手机运行预算

| 有效性能档 | 舞台发布频率上限 | 动态粒子上限 | 栅格最长边 | 单套缓存像素总上限 |
| --- | --- | --- | --- | --- |
| Lightweight | 只在歌词/间奏边界及设置变化时绘制 | 0 | 360 px | 129600 |
| Balanced | 30 fps | 12 | 540 px | 291600 |
| HighPerformance | 60 fps | 24 | 720 px | 518400 |

像素预算包含背景、星图盘和船只附加图层。ARGB 缓存单套最多约 0.50 / 1.12 / 1.98 MiB；它不表示整款播放器或系统 GPU 缓存的内存上限。

- 文档编排、排序、字形分段、文字测量和背景准备在 Default 执行。每个舞台只有一条背景准备通道，过期任务可取消；尚未发布的取消结果立即回收。
- 当前场景保留到替换结果就绪，尺寸变化期间缩放旧场景过渡。隐藏或退出 RESUMED 状态时停止准备并释放持有的背景结果。
- Canvas 有独立显示列表；工具栏的波纹等局部动画不会重复调用歌词绘制。宿主位置事件只为插值重新定位，持续绘制由 30/60 fps 门限发布。
- 入场阶段最多 96 个动画字形。稳定阶段整段绘制，已完成字形合并为行内裁剪块；仅正在高亮的字形更新部分裁剪，不逐字重复绘制整个持有阶段。复杂文字保留 Android 完整段落排版。
- 长句使用均衡断行避免短尾行，歌词与辅助文本之间留出明确间距；辅助文本仍按原文排版，不截断罗马音/译文。
- 轻量档及无运动、无时间词的静态场景，不因每个宿主进度事件重绘；仍保持歌词切换、间奏、Seek 和偏移正确。
- 暂停、切歌和倍速变化重新定位；宿主停更时插值最多推进 650 ms。源时间词及估计高亮开关继续沿用现有行为。
- 超过 4096 行、单句/辅助文本超过 1024 字符、单句超过 256 个时间词或无法完整放入舞台时，回退普通歌词视图，不截断原文。
- 同时间戳合唱文字合并展示，空白时间戳结束唱词但保留上下文。封面风格变化不覆盖 Afterglow 选择。

## 短验证结果

独立 x86_64 Android 36 模拟器、SwiftShader、Debug、1080×2400 硬件 Canvas；同一 96 字、持续高亮场景，预热 12 帧后采集 96 次绘制函数耗时。整帧采集 107 帧，使用 [FrameMetrics](https://developer.android.com/reference/android/view/FrameMetrics)，不把绘制函数 CPU 时间当作整帧时间。

| 指标 | 优化前 P95 | 优化后 P95 |
| --- | --- | --- |
| 绘制函数 CPU | 0.759 ms | 0.501 ms |
| 显示列表绘制阶段 | 0.975 ms | 0.738 ms |
| 整帧 | 18.782 ms | 12.610 ms |

优化后样本已包含更丰富的星海航行场景，其栅格缓存为 562512 字节，准备耗时约 16.2 ms（生产舞台在后台准备）。CPU P95 下降约 34%，整帧 P95 下降约 33%。这是本次受控场景观测，不能推导所有手机、整款播放器或 Release 耗电结论。

独立 Compose 舞台已检查六个场景及选择菜单。短采样中，暂停 1.2 秒、后台稳定后 1.2 秒、轻量档播放稳定画面 1 秒均为 0 新增绘制帧。按钮波纹等整窗动画的过渡样本不用于判断舞台持续刷新率。

全屏布局另在真实 `NowPlayingScreen` 中使用所报告的长日文句子、罗马音和中文译文验证：默认隐藏所有控制、点击显示、自动收起、菜单打开 5 秒仍保持可用、从设置选择另一套 Afterglow 后保持全屏且控制隐藏，以及返回普通封面。

相关单测覆盖限频、时钟/歌词边界/间奏/合唱、时间词匹配和各场景共享像素预算；另运行本模块编译、`checkLocalization` 和打包。测试探针与独立模拟器不加入默认 CI。真机 Release、导入字体、发热、耗电及与实际音频播放同时运行仍需设备验收。
